================================================================================
     GUÍA COMPLETA DE INSTALACIÓN - SAC WEB
     Sistema de Administración de Condominios
     Para principiantes - Paso a paso
================================================================================


ANTES DE EMPEZAR - PROGRAMAS QUE DEBES DESCARGAR

Estos programas NO se instalan con comandos. Debes descargarlos de internet:

1. Python 3.13
   Descargar de: https://www.python.org/downloads/
   
2. Node.js 22
   Descargar de: https://nodejs.org/
   
3. Google Chrome
   Descargar de: https://www.google.com/chrome/
   
4. Visual Studio Code (opcional pero recomendado)
   Descargar de: https://code.visualstudio.com/


================================================================================
PASO 1: INSTALAR PYTHON
================================================================================

1.1. Abre tu navegador y ve a:
     https://www.python.org/downloads/

1.2. Haz clic en el botón amarillo "Download Python 3.13.x"

1.3. Ejecuta el archivo descargado

1.4. IMPORTANTE: En la primera pantalla del instalador, marca estas dos opciones:
     [X] Add Python to PATH
     [X] Use admin privileges when installing py
     
1.5. Haz clic en "Install Now"

1.6. Espera a que termine y cierra el instalador


VERIFICAR QUE PYTHON SE INSTALÓ CORRECTAMENTE:

Abre PowerShell (busca "PowerShell" en el menú inicio) y escribe:

python --version

Debes ver algo como: Python 3.13.1

Si dice "python no se reconoce", reinicia la computadora e intenta de nuevo.


================================================================================
PASO 2: INSTALAR NODE.JS
================================================================================

2.1. Abre tu navegador y ve a:
     https://nodejs.org/

2.2. Descarga la versión LTS (el botón de la izquierda)

2.3. Ejecuta el archivo descargado

2.4. Sigue el instalador con las opciones por defecto (Next, Next, Install)

2.5. Espera a que termine y cierra el instalador


VERIFICAR QUE NODE.JS SE INSTALÓ CORRECTAMENTE:

Abre una NUEVA ventana de PowerShell y escribe:

node --version

Debes ver algo como: v22.11.0

También verifica npm:

npm --version

Debes ver algo como: 10.9.0


================================================================================
PASO 3: INSTALAR GOOGLE CHROME
================================================================================

3.1. Ve a: https://www.google.com/chrome/

3.2. Descarga e instala Chrome normalmente

3.3. No necesitas abrirlo, solo tenerlo instalado

(El sistema usa Chrome internamente para generar los PDFs)


================================================================================
PASO 4: COPIAR EL PROYECTO A LA NUEVA PC
================================================================================

4.1. Copia toda la carpeta "sac_web" a la nueva computadora

4.2. Ubicación recomendada: C:\Proyectos\sac_web

4.3. Puedes usar una USB, disco externo, o comprimirlo en ZIP

IMPORTANTE: NO copies la carpeta "venv" ni "node_modules", las vamos a crear nuevas.


================================================================================
PASO 5: ABRIR LA TERMINAL EN LA CARPETA DEL PROYECTO
================================================================================

5.1. Abre el Explorador de archivos

5.2. Navega hasta: C:\Proyectos\sac_web

5.3. Haz clic derecho en un espacio vacío

5.4. Selecciona "Abrir en Terminal" o "Abrir ventana de PowerShell aquí"

También puedes:
- Abrir PowerShell desde el menú inicio
- Escribir el siguiente comando para ir a la carpeta:

cd C:\Proyectos\sac_web


================================================================================
PASO 6: CREAR EL ENTORNO VIRTUAL DE PYTHON
================================================================================

Con la terminal abierta en la carpeta del proyecto, escribe:

python -m venv venv

Espera unos segundos. Se creará una carpeta llamada "venv".


================================================================================
PASO 7: ACTIVAR EL ENTORNO VIRTUAL
================================================================================

Escribe este comando:

venv\Scripts\activate

Sabrás que funcionó porque verás (venv) al inicio de la línea:

(venv) PS C:\Proyectos\sac_web>


SI TE DA ERROR DE PERMISOS:

Cierra PowerShell y ábrelo como administrador:
1. Busca "PowerShell" en el menú inicio
2. Clic derecho -> "Ejecutar como administrador"
3. Escribe:

Set-ExecutionPolicy RemoteSigned -Scope CurrentUser

4. Escribe "S" para confirmar
5. Ahora vuelve a intentar activar el entorno:

cd C:\Proyectos\sac_web
venv\Scripts\activate


================================================================================
PASO 8: INSTALAR LAS DEPENDENCIAS DE PYTHON
================================================================================

Con el entorno virtual activado (debes ver (venv) al inicio), escribe:

pip install -r requirements.txt

Esto descargará e instalará:
- Django (el framework web)
- WeasyPrint (para generar algunos PDFs)
- openpyxl (para exportar a Excel)
- Pillow (para manejar imágenes)
- Y otras librerías necesarias

Espera a que termine. Puede tardar varios minutos.


SI TE DA ERROR CON WEASYPRINT:

WeasyPrint necesita GTK. Descárgalo de:
https://github.com/nicolarevelant/GTK-MSI

1. Descarga el archivo .msi
2. Instálalo
3. Reinicia la terminal
4. Vuelve a ejecutar: pip install -r requirements.txt


================================================================================
PASO 9: INSTALAR LAS DEPENDENCIAS DE NODE.JS
================================================================================

En la misma terminal (con venv activado o no, da igual), escribe:

npm install

Esto descargará Puppeteer (para generar los recibos PDF).
La primera vez puede tardar varios minutos porque descarga Chrome.


SI TE DA ERROR DE NPM:

Intenta ejecutar la terminal como administrador y repite el comando.


================================================================================
PASO 10: VERIFICAR LA BASE DE DATOS
================================================================================

Si copiaste el archivo db.sqlite3, los datos ya están.

Si quieres empezar con base de datos vacía, ejecuta:

python manage.py migrate


================================================================================
PASO 11: CREAR USUARIO ADMINISTRADOR (SOLO SI ES BASE NUEVA)
================================================================================

Si empezaste con base de datos vacía, crea un usuario:

python manage.py createsuperuser

Te pedirá:
- Nombre de usuario: (escribe el que quieras)
- Correo electrónico: (puedes dejarlo vacío, presiona Enter)
- Contraseña: (escribe una contraseña, no se ve mientras escribes)
- Confirmar contraseña: (repite la contraseña)


================================================================================
PASO 12: INICIAR EL SERVIDOR
================================================================================

OPCIÓN A - Con el archivo BAT (más fácil):

Haz doble clic en el archivo: INICIAR_SERVIDOR.bat


OPCIÓN B - Desde la terminal:

Asegúrate de tener el entorno virtual activado y escribe:

python manage.py runserver


================================================================================
PASO 13: ABRIR EL SISTEMA EN EL NAVEGADOR
================================================================================

Abre Google Chrome y escribe en la barra de direcciones:

http://127.0.0.1:8000

O también funciona:

http://localhost:8000

RESUMEN DE COMANDOS (COPIA Y PEGA)

================================================================================
SOLUCIÓN DE PROBLEMAS
================================================================================

PROBLEMA: "python" no se reconoce como comando
CAUSA: Python no está en el PATH
SOLUCIÓN:
1. Desinstala Python
2. Vuelve a instalarlo marcando "Add Python to PATH"
3. Reinicia la computadora


PROBLEMA: "npm" no se reconoce como comando
CAUSA: Node.js no está en el PATH
SOLUCIÓN:
1. Reinicia la computadora
2. Si persiste, reinstala Node.js


PROBLEMA: Error al activar el entorno virtual
CAUSA: Políticas de ejecución de PowerShell
SOLUCIÓN: Ejecuta como administrador:
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser


PROBLEMA: Error al instalar WeasyPrint
CAUSA: Falta GTK
SOLUCIÓN: Instala GTK desde:
https://github.com/nicolarevelant/GTK-MSI


PROBLEMA: Error al generar PDF
CAUSA: Chrome no está instalado
SOLUCIÓN: Instala Google Chrome


PROBLEMA: La página no carga
CAUSA: El servidor no está corriendo
SOLUCIÓN: Asegúrate de ejecutar "python manage.py runserver"


PROBLEMA: Error de puerto en uso
CAUSA: Otra aplicación usa el puerto 8000
SOLUCIÓN: Usa otro puerto:
python manage.py runserver 8080
Y abre: http://127.0.0.1:8080
